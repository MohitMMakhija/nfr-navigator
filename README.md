# AI Governance Hub

This is strictly a static/mock UX prototype: no real AI, APIs, document parsing, OCR, integrations, authentication, or secrets. Make simulated AI clearly labeled POC DEMO MODE and show a small demo reset action.

Prioritize a polished desktop enterprise governance control-tower experience and complete end-to-end clickable demo journey. Implement application shell/nav, Project Manager executive dashboard for Smart Grid Modernisation / TP500 / Stage Gate A / Assessment #001, KPI 72% compliance, 94 requirements, 18 risks, 8 red; compliance framework drilldowns; project/assessment wizard; populated artefact upload (6 files); visually compelling simulated seven-step AI assessment progression; results; clickable compliance heatmap; policy library and policy/requirement detail with evidence, static reasoning, confidence and gaps; evidence traceability page; risk cockpit/matrix/detail; mitigation recommendations with accept/modify/reject state changes; human-in-loop approval with audit trail; persona switcher that changes dashboard emphasis for all five specified personas; AI explainability; assessment trace; Stage Gate A conditional readiness; executive-summary mock generation; POC success metrics. Use consistent RAG and risk scoring given in brief. Create clean mock service/data boundaries for future integration but do not actually integrate anything. Please make high-quality visual and interaction decisions from the full user brief.
